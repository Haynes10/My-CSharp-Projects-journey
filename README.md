CarInsurance MVC Project

This project is a Car Insurance Management System built using C# and ASP.NET Core MVC.
It demonstrates the use of Models, Views, and Controllers (MVC) architecture in building a structured web application.

Features

User-friendly web interface for managing car insurance details

Demonstrates MVC principles (Controllers, Models, Views)

Form handling and validation

Data display and organization

Scalable structure for future expansion

  Technologies Used

C#

ASP.NET Core MVC

.NET Framework / .NET 6 (depending on your version)

Entity Framework


⚙️ Setup & Installation

Clone the repository:

git clone https://github.com/Haynes10/My-CSharp-Projects-journey.git


Open the solution (CarInsurance.sln) in Visual Studio 2022

Restore dependencies (NuGet packages)

Run the project using IIS Express or dotnet run

📖 How It Works

The Model defines the car insurance data structure

The Controller handles business logic and user requests

The Views display dynamic content to the user

📌 Purpose

This project was built to practice and demonstrate MVC concepts in ASP.NET and apply problem-solving through C# programming.
